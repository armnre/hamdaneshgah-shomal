# هم‌دانشگاهی — شبکه دانشجویی دانشگاه شمال

پلتفرم فارسی و راست‌چین فعالیت‌های دانشجویی دانشگاه شمال آمل: انجمن‌های علمی، دانشکده‌ها، اخبار، رویدادها و پنل مدیریت نقش‌محور.

## دیپلوی روی Netlify + Neon

پوشه `deploy/` نسخه مستقل و قابل‌دیپلوی پروژه است. همان کد صفحات و اندپوینت‌های `apps/app` را استفاده می‌کند. تنها چیزی که عوض می‌شود لایه‌ی زیرساخت است:

| بخش | پیاده‌سازی روی Netlify |
|---|---|
| فرانت‌اند | Vite → `deploy/dist` |
| API | یک Netlify Function (`/api/*`) که همه اندپوینت‌های `apps/app/src/api` را اجرا می‌کند |
| دیتابیس | Neon Postgres (`deploy/db/schema.sql`؛ هر دیپلوی به‌صورت خودکار مایگریشن و seed را اجرا می‌کند) |
| ورود | ورود بدون رمز با پیوند ایمیلی (Magic Link) و کوکی امضاشده HttpOnly؛ ارسال ایمیل از طریق Resend |
| فایل‌ها | Netlify Blobs (`/api/upload` و `/api/file/:key`) |

### راه‌اندازی
1. در Netlify گزینه **Add new site → Import from GitHub** را بزنید و این مخزن را انتخاب کنید. تنظیمات از `netlify.toml` خوانده می‌شود (base = `deploy`).
2. در **Site settings → Environment variables** این مقادیر را تعریف کنید:

| متغیر | توضیح |
|---|---|
| `DATABASE_URL` | رشته اتصال Neon (pooled). **بعد از تعویض پسورد، مقدار جدید را وارد کنید.** |
| `SESSION_SECRET` | رشته تصادفی ۳۲+ کاراکتری، مثلاً خروجی `openssl rand -base64 48` |
| `RESEND_API_KEY` | کلید API از resend.com برای ارسال ایمیل ورود |
| `MAIL_FROM` | فرستنده ایمیل، مثلاً `هم‌دانشگاهی <no-reply@your-domain.ir>` (دامنه باید در Resend تأیید شده باشد) |
| `ZITE_BOOTSTRAP_ADMIN_EMAILS` | ایمیل(های) مجاز برای ساخت مدیر کل اولیه، جداشده با ویرگول |
| `SITE_URL` | (اختیاری) آدرس نهایی سایت. اگر خالی باشد، `URL` خود Netlify استفاده می‌شود. |

3. سایت را Deploy کنید. سپس به `/admin` بروید، با ایمیل مجاز وارد شوید و «ثبت من به‌عنوان مدیر کل» را بزنید.

### توسعه محلی
```bash
cd deploy && npm install
npx netlify dev     # فرانت + فانکشن‌ها با متغیرهای محیطی Netlify
```

## ساختار
- `apps/app/src/pages` — صفحات عمومی
- `apps/app/src/admin` — پنل مدیریت (فقط از مسیر `/admin`)
- `apps/app/src/api` — اندپوینت‌های سرور
- `apps/app/src/lib/policy.ts` — قواعد مجوز (تست‌شده در `apps/app/tests`)
- `deploy/server` — لایه‌ی سازگاری Neon/Netlify (`db.ts`، `auth.ts`، `handler.ts`)
- `packages/components` — کامپوننت‌های مشترک (shadcn/ui)

## امنیت
- هیچ کلید یا رمزی داخل مخزن نیست. همه از متغیرهای محیطی خوانده می‌شوند.
- پیوند ورود یک‌بارمصرف است، ۱۵ دقیقه اعتبار دارد و فقط هش آن ذخیره می‌شود. برای هر ایمیل حداکثر ۵ درخواست در ساعت پذیرفته می‌شود.
- درخواست‌های تغییر داده فقط از همان مبدأ پذیرفته می‌شوند. هدرهای امنیتی در `netlify.toml` تنظیم شده‌اند.
- ساخت مدیر کل فقط وقتی ممکن است که هنوز هیچ مدیری وجود نداشته باشد و ایمیل در allowlist باشد. یک index یکتا هم از ثبت دوباره جلوگیری می‌کند.

## تصاویر
تصاویر پوشه `apps/app/public/shomal` از وب‌سایت رسمی دانشگاه (shomal.ac.ir) گرفته شده‌اند و متعلق به دانشگاه شمال هستند.
