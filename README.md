# هم‌دانشگاه شمال (Shomal Student Hub)

پلتفرم فارسی و راست‌چین فعالیت‌های دانشجویی دانشگاه شمال آمل — انجمن‌های علمی، دانشکده‌ها، اخبار، رویدادها و پنل مدیریت نقش‌محور.

> این مخزن خروجی کد یک پروژه ساخته‌شده روی پلتفرم **Zite** است.
> بخش سرور و دسترسی به داده به ماژول‌های `zitejs/*` وابسته‌اند و **بدون بازنویسی روی سرور مستقل اجرا نمی‌شوند**.
> جزئیات در [`apps/app/docs/audit.md`](apps/app/docs/audit.md).

## ساختار
- `apps/app/src/pages` — صفحات عمومی
- `apps/app/src/admin` — پنل مدیریت
- `apps/app/src/api` — اندپوینت‌های سرور (Zite Worker)
- `apps/app/src/lib/policy.ts` — قواعد مجوز بدون وابستگی به پلتفرم
- `apps/app/tests` — تست‌های واحد (`npm test` داخل `apps/app`)
- `packages/components` — کامپوننت‌های مشترک (shadcn/ui)

## تصاویر
تصاویر پوشه `apps/app/public/shomal` از وب‌سایت رسمی دانشگاه (shomal.ac.ir) گرفته شده‌اند و متعلق به دانشگاه شمال هستند.
