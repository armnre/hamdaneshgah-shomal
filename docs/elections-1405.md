2. **ماهان طباطبایی** (مدیریت): شماره‌ی دانشجویی ندارد. احتمالاً همان «سیده ماهان طباطبایی» (۴۰۳۲۲۷۲۰۰۶) است که وارد شده است.

## تکمیل فهرست (مایگریشن 0009)
شماره دانشجویی نامزد اختیاری شد. «جواد محمدپور» (حقوق)، «ماهان طباطبایی» (مدیریت) و «ملینا نجاریان» (علوم تربیتی) بدون شماره دانشجویی وارد شدند. «ابوالفضل عابدی» تکراری بود و یک‌بار ثبت شده است. تا پیش از شروع رأی‌گیری، نامزدها از پنل مدیریت قابل افزودن، ویرایش و حذف هستند.

## پیش از روز رأی‌گیری
فهرست دانشجویان واجد شرایط هر رشته را از پنل مدیریت ← «ورود رأی‌دهندگان» بارگذاری کنید. هر دانشجو فقط در انتخابات رشته‌ی خودش و فقط یک‌بار می‌تواند رأی بدهد.

## ورود فهرست رأی‌دهندگان (۵۶۱۹ دانشجو)

فایل اکسل دانشجویان شامل کد ملی است و **نباید** در گیت قرار بگیرد. آن را مستقیم روی سرور بگذارید (مثلاً `/root/students.xlsx`) و اجرا کنید:

```bash
cd /var/www/vhosts/anjoman.shomal.ac.ir/app/server
npm run import-voters -- /root/students.xlsx            # آزمایشی: فقط شمارش و خطاها
npm run import-voters -- /root/students.xlsx --commit   # ثبت نهایی
shred -u /root/students.xlsx                            # حذف فایل پس از ثبت
```

هر دانشجو به انتخابات انجمن رشته‌ی خودش می‌رود (همه‌ی مقاطع). گرایش‌ها به رشته‌ی اصلی می‌روند؛
مهندسی پزشکی، الکترونیک ← برق و پزشکی؛ مکاترونیک ← مکانیک؛ نقشه‌برداری و شهرسازی ← عمران؛
علوم قضایی ← حقوق؛ حسابرسی ← حسابداری؛ تربیت بدنی و همه‌ی گرایش‌های ورزشی (حتی مدیریت ورزشی) ← علوم ورزشی.
کد ملی فقط به‌صورت HMAC با `ZITE_VOTER_PEPPER` ذخیره می‌شود. اجرای دوباره، رأی‌دهنده‌ی تکراری نمی‌سازد.

## نامزدهای نیازمند بررسی (مایگریشن 0011)

۱۴ نامزد با برچسب «نیاز به بررسی» در پنل مدیریت مشخص‌اند (شماره‌ی دانشجویی آن‌ها خالی شد):
شماره‌ی متعلق به شخص دیگر (حسین اسدالهی، رقیه قلی‌پور، صبا عزیزپور، مهدی حسینی ایمنی، ملینا نجاریان)،
شماره‌ی ناموجود در فهرست (سامی فلاح، سید رسول مجیدی، ستایش وحیدی، فریبرز علایی، امیررضا ایرائی‌پور، بهار مسلمی، امیررضا زارع)،
و بدون شماره (جواد محمدپور، ماهان طباطبایی). «نگین رزی» به «نگین درزی» اصلاح شد و ردیف اشتباه «فاطمه کرد» حذف شد.
